# backend

Our own small services that run outside Vellum. Bun + TypeScript, same as Vellum.

Planned first service: the **router**. All testers share one phone number and one WhatsApp
number. The router looks up the caller's phone number, finds that tester's own Vellum
assistant, and forwards the call or message to it. Creating a new assistant for a new tester
will also live here.

Nothing is built yet.
