# Bunty Website

Static public website for Bunty personal AI assistant.

Built with semantic HTML5, pure CSS custom properties, and minimal vanilla JavaScript.
No CSS frameworks, build steps, or external runtime dependencies.

## How to run locally

```bash
python3 -m http.server 8080
```

Open http://localhost:8080 in any modern web browser.

## Deployment

Configured for deployment to Cloudflare Pages or static hosting services.
Deploy root directory: `website/`.
